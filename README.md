# whatsapp-business-service

A lightweight Node.js + TypeScript service for whatsapp business API.

* Create and configure it all by following [the guide](https://developers.facebook.com/documentation/business-messaging/whatsapp/get-started).
* When things seem to be missing from the docs, kindly ask an LLM to fill in the gaps.
